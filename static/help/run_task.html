Reports (run a saved report)

Run a report that someone already built. Upload this month's files, click Run, and get the finished report. You type nothing.

A saved report is called a task. It remembers the files it expects, how they link, the questions asked, the checks, and the layout. It is built once in Report builder and run every month here.

Steps

  1. Pick a report. Use Search tasks to find it, or sort by Last saved or Name (A-Z). Click its Run button.
    Not sure what to upload? Click Schema. It lists the files the report expects and their columns. You can Download a blank file for each, with the right headings.
  2. Step 1: Current files. Upload this month's Excel or CSV files.
  3. Step 2: Does it match the task? The app compares your files with what the report expects and tells you what is missing or different.
    • If a file or column has a different name (for example "Emp Code" instead of "Employee Code"), use the mapping boxes to say which uploaded file is which table and which column is which. Use Clear the mapping to undo.
  4. Keep the box about redrafting comments ticked if you want fresh comments for this month's figures. Untick it to keep the wording saved with the report (use this if you wrote the comments yourself).
  5. Click Run task. The app shows what it is doing, step by step.
  6. The report. Read the summary (it tells you if any step failed). Then view, update and download the report: Preview, Update, Download.

Example: monthly salary report

  1. Search "Salary" and click Run on Salary Review.
  2. Click Schema. It needs Employee Master and Salary. Upload this month's two files.
  3. The match shows "Salary: column Net Pay not found". Your file calls it "Net Amount". Map Net Amount to Net Pay.
  4. Click Run task. Wait for it to finish.
  5. Open Download, and download the HTML or Excel report.

After the run

  • Chat opens Chat with reports on this report's data, so you can ask more questions. No upload needed.
  • Dashboard shows the report's saved dashboard on its latest data (view and download only).
  • Pick another goes back to the list. Start over and Clear all files clear the page.
Watch out
  • Running restores the report's links and column meanings onto your files, and replaces any you set by hand in this session.
  • You only see your own reports. If the list is empty, a report has to be built first in Report builder (admins only).
