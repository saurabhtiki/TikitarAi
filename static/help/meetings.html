Meetings: how to set up a meeting

A meeting is a chat where the AI talks to your people (candidates, vendors, customers) for you, asks your questions, and collects the answers. You only set it up once.

1. Set up in 7 steps

Click New meeting. A window opens. Fill it from top to bottom.

  1. Start from. Pick a ready template (HR interview, Vendor purchase, Sales quotation, Project review, AR review) and click Use template. Everything below fills in. You can change it. Or choose to start blank.
    Short on time? Type what you want in Describe it in plain English, for example "Interview an accountant, ask salary and notice period", and click Draft with AI.
  2. Subject. The meeting name. Example: Accountant interview - November.
  3. Meeting context. Tell the AI the purpose in 2-3 lines. Example: We are hiring an accountant for our Pune office. Be polite and short.
  4. Persona (optional). Who the AI should act as. Example: HR executive of ABC Traders.
  5. Context / SOP (optional). Rules the AI must follow. Example: Never promise a job. Salary talk only with the HR head.
  6. Agenda. The list of things to ask. See section 2.
  7. Invitees (optional). Add name and email of each person. You can also add them later. Then click Create meeting.
TipLike what you built? Click Save as template to reuse it next time. Your templates show as "(mine)" in Start from.

2. Agenda: what to ask

Each row of the agenda grid is one thing to cover. Every row has a Type:

TypeUse it whenExample
DiscussionYou want the AI to talk about a topic freely."Tell about our company and the job."
QuestionYou need one exact answer, checked by rules."Expected salary?" (a number)
TableThe person must fill a grid of rows and columns.A vendor's price list.

Items are covered in the order you list them. Question items are asked first, one at a time ("Question 2 of 5").

3. Question items

For a Question row, fill these cells:

CellWhat it means
Answer typeText, Number, Date, Yes/No, or Choice.
RuleWhat a correct answer looks like. Empty = anything is fine.
TriesHow many times the person may try. If a wrong answer is given, the AI asks again and uses one try. After the last try, "Not answered" is saved and the chat moves on. A side question does not use a try.
Go toSkip ahead depending on the answer. See section 4.
For eachRepeat for every row of a list. See section 5.

Rule examples

Answer typeRule you typeMeaning
Numberbetween 20000 and 60000Salary must be in this range
DatefutureDate must be after today
DatepastDate must be before today
Dateafter 01-10-2026Date must be after this day
Datewithin 30 daysDate must be within 30 days of today
Textat least 20 charactersNot too short
ChoiceMorning, Evening, NightOnly these choices are allowed
ExampleRow: Preferred shift | Question | Choice | Morning, Evening, Night | Tries 3.
The candidate writes "evening please". The AI understands it as Evening and saves it. If they write "lunch time", it asks again (1 try used).
Good to knowThe AI only turns the reply into the right form (for example "45k" becomes 45000). The app itself checks the Rule, so the AI cannot let a wrong answer pass.

4. Flow: skip questions with Go to

Use Go to when the next question depends on the last answer. You write if (condition) go to (question name). For several conditions, separate them with ;. The first one that matches wins.

  • Go to only jumps forward: to a later question or to End. Never back.
  • Number conditions: if > 60000, if < 10. Yes/No or Choice: if No, if Evening. Text answers cannot branch.
  • If the question was "Not answered", it never branches. The chat just goes to the next question.

Full example: stop early if the salary is too high

Goal: If the expected salary is above 60,000, end politely. Otherwise ask the notice period.

Step 1. Fill the agenda grid:

ItemTypeAnswer typeRuleGo to
Expected salaryQuestionNumberbetween 10000 and 200000if > 60000 go to End; if > 0 go to Notice period
Notice periodQuestionNumberbetween 0 and 90
Can you join on 1st of next month?QuestionYes/No

Step 2. Look at the Flow picture under the grid. Blue arrows are your Go to jumps. A red ? means a Go to points to a place that does not exist, or backwards. Fix it before you click Create meeting.

Expected salary --(if > 60000)--------------------> End
      |
      '--(if > 0)--> Notice period --> Can you join...? --> End

Step 3. Here is what happens in the chat:

Candidate saysWhat the app does
"80000"80000 is more than 60000, so the first Go to matches. Notice period and the joining question are skipped, and the chat ends politely.
"45k"AI reads 45000. It is not above 60000, so the second Go to matches. The AI asks Notice period, then the joining question.
"5 lakh"500000 is above the Rule limit (200000). The AI says "500000 is too high" and asks again. One try is used.
Watch outIf your Go to uses a number beyond the Rule's limit, for example if > 300000 with Rule between 10000 and 200000, that jump can never happen. The app shows a red note about it.

5. For each: ask the same questions for every row of a list

Example: a customer has 3 unpaid invoices. You want to ask, for each invoice, "When will you pay?" Instead of writing 3 sets of questions, type the same list name in For each, for example Outstanding invoices.

  1. Give these question rows the same name in the For each cell. Keep them together, one below the other.
  2. Create the meeting. Open Overview and upload the list (Excel or CSV).
  3. By default every invitee gets all rows. To give each person only their own rows, open Advanced and set the Match column (a column with the person's name or email).
  4. Choose the Row name column (for example Invoice no.), so the chat says "INV-102: row 2 of 3".

Inside such a list, a Go to can say Next row to jump straight to the next row of the list.

6. Table items: the person fills a grid

Use a Table when chatting is not enough, for example a vendor sending prices for many items.

Full example: a vendor price list

Step 1. In the agenda add one row: Item = Price list, Type = Table.

Step 2. Click Create meeting. Open Overview and upload an Excel/CSV for that item. Fill what you know and leave the rest blank for the vendor:

Item nameQtyYour priceDelivery date

Step 3. In Overview set the column rules for the columns the vendor fills, then click Save column rules:

Step 4. What the vendor sees:

  • A separate tab with this grid and a line "You can fill in: Your price, Delivery date".
  • Item name and Qty are already filled and cannot be changed.
  • If they type "abc" as a price, the app refuses it when they click Save progress.

Step 5. You compare all vendors in Comparisons → Table comparisons.

7. Evaluation questions: compare people on the same points

These are optional. The AI slips them naturally into the chat and notes the answer. The person does not see this list. Later you can compare everyone side by side.

Full example: hiring an accountant

In the Evaluation questions grid:

QuestionBuckets (optional)
How much Tally experience does the candidate have?Beginner, Intermediate, Expert
How confident did the candidate sound about GST work?Low, Medium, High
Would the candidate be happy to work on Saturdays?
  • The candidate says "I have used Tally for 6 years". The AI marks Expert.
  • With Buckets, the answer is one of the words you gave. Good for counting and filtering.
  • With no buckets (the third question), the AI writes a short answer in its own words.
  • See everyone together in Comparisons → Evaluation answers.

8. FAQ: let the AI answer side questions

People ask things like "Where is the office?" The AI answers only from your context, SOP, agenda notes and FAQ. It never guesses from general knowledge.

  • In the FAQ table add pairs: Question | Answer. Or click Download template, fill it in Excel, and upload it (maximum 300 rows).
  • Example: Question What are the working hours? Answer 9:30 AM to 6:00 PM, Monday to Saturday.
  • If the AI cannot answer, the question is saved for you in Overview. Type the answer and click Add to FAQ. Next time it is answered.

9. After you create the meeting

Open the meeting from the list (use Find a meeting to search). It has these tabs:

TabWhat you do there
OverviewChange the AI model, upload lists and tables, set column rules, edit the FAQ, edit the "How to use" steps shown to invitees, see the Flow picture.
Invitees & statusSee who has joined, who is finished, files they attached. Use Add invitee for more people.
View chatRead each chat. Download as .txt or Excel.
View summaryRead the AI summary. Download as .txt.
ComparisonsQuestion answers, List answers, Consolidated MoM, Evaluation answers, Table comparisons.
ShareCopy each invitee's personal link and code and send it to them.
What your invitee doesThey open their link, enter the code, and chat. A panel on the left shows How to use, the Agenda and Attach a file. When all questions are done, Close chat becomes available.

10. Common problems

ProblemWhat to do
Red ? in the Flow pictureA Go to points to a question that does not exist or comes earlier. Check the spelling of the question name, and point only forward.
Create meeting shows an error about the agendaRead the red message. Usual causes: a Question row without Answer type, a Rule that does not fit the type, or a Go to condition on a Text answer.
Invitee cannot open the linkCheck the link and code in Share. Send them again.
The AI model is missingThe model you picked was deleted. The default one is used instead. Pick another in Overview.
For each list shows 0 rowsThe Match column found no row for that person. Clear the Match column to give everyone all rows, or fix the names/emails in your sheet.
DatesAlways write dates as dd-mm-yyyy, for example 15-11-2026.
