Chat with reports

Ask questions about the latest data of a report that has already been run. No upload, no setup.

Steps

  1. Pick a report from the list. Only reports that have been run at least once appear here.
  2. The page shows when the data was last refreshed and by whom, and the tables you can ask about.
  3. Type your question at the bottom. Ask for a number, a table or a chart.
  4. Open SQL that ran under an answer to see how it was worked out.
  5. Use Clear this chat to start fresh, or Pick another report to switch.

Examples

You typeYou get
Top 10 customers by sales this monthA table of 10 rows.
Show department-wise net pay as a chartA chart of the answer.
How many employees have overtime above 50 hours?A number.
Good to know
  • The report's data is shared: everyone who logs in can ask questions of it. The report's recipe stays with its owner.
  • It is read only. You cannot add or change columns here, because everyone reads the same data. Ask for that in Chat with data instead.
  • Nothing is saved: the chat is not stored, and there is no Pin to Dashboard. For something to keep, use Chat with data.
  • The buttons Chat with data and Dashboard on this page open the same data in those pages.
