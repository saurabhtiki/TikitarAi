Settings

Change your profile and password, and manage the AI models the app uses.

At the top choose a section: Profile, Password or LLM providers.

Profile

  1. Change your Name.
  2. Upload a Profile photo if you like.
  3. Click Save profile.

Password

  1. Type your Current password.
  2. Type the New password and the same again in Confirm new password.
  3. Click Change password.
If it is refusedThe current password may be wrong, or the two new passwords may not match. Try again.

LLM providers (the AI models)

The AI that answers your questions, writes summaries and talks in meetings is a "model". Here you store the connections to the models. Each saved connection is a profile.

Add a model

  1. Click Add new.
  2. Choose the Provider type:
    • cloud: a company service such as OpenAI. Needs an API key.
    • local: a program on your own computer (LM Studio, Ollama). No key needed.
    • custom: any other service that works the same way. Needs a Base URL.
  3. Give a Nickname you will recognise, for example My OpenAI.
  4. Fill the Base URL (needed for local and custom) and the API key (stored encrypted).
  5. In Models type the model names, one per line or separated by commas, for example gpt-4o-mini, gpt-4o. One profile is saved for each model.
  6. Click Save.

Use your profiles

ButtonWhat it does
Test connectionChecks that the model answers. Do this after adding one.
Set as defaultEvery new session starts on this model. Unset default removes it.
Set as light modelUsed automatically for small, quick jobs such as reading a typed instruction or drafting a checklist. Pick a cheap, fast model. Unset light model removes it.
EditChange a profile's details. Leave the key blank to keep the saved one, or tick Remove saved key.
DeleteRemoves a profile after you confirm. A meeting that used it falls back to your default model.
TipThe key is saved on each profile. If you change a key later, edit every profile of that group.
ExampleAdd one OpenAI group with models gpt-4o and gpt-4o-mini. Set gpt-4o as default (best answers) and gpt-4o-mini as light model (cheap, fast).
