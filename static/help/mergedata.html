Merge Files

Join Excel files side by side using a matching column, like VLOOKUP, but for whole tables. You can merge many tables one after another.

Steps

  1. Step 1: Upload. Select one or more Excel files. Every sheet becomes its own dataset. A table lists them with rows and columns.
  2. Step 2: Preview. Open any dataset to see its first 20 rows.
  3. Step 3: Merge.
    1. Choose the Left dataset and the column(s) to match on.
    2. Choose the Right dataset and its matching column(s). Left and Right need the same number of matching columns.
    3. Choose the Merge type (see below).
    4. Choose the columns to include in the result. By default all are included.
    5. Click Merge these two datasets.
  4. The result becomes the new Left. Pick another remaining dataset on the Right and merge again, until all are used.
  5. Click Download final merged dataset (Excel). The file also has a Merge_Log sheet that records each step.

Merge type: which rows to keep

TypeKeeps
leftAll rows of the Left. Right details are filled where a match exists, blank otherwise.
rightAll rows of the Right.
innerOnly rows that match on both sides.
outerEverything from both sides.

Example: add city to the sales list

sales.xlsx has Customer Code, Amount. customers.xlsx has Code, Name, City.

  1. Upload both. Left = sales, matching column Customer Code.
  2. Right = customers, matching column Code.
  3. Merge type = left (keep every sale even if the customer is not found).
  4. Click Merge. Each sale now has Name and City. Download.
Good to know
  • Made a mistake? Click Undo in the Merge log. It undoes the last merge only.
  • If the two matching columns are of different kinds (one number, one text), the app warns you and compares both as text.
  • If both tables have a column with the same name, the app adds the dataset name to each so nothing is lost.
  • If you remove an uploaded file that was already merged, the merge is reset.
