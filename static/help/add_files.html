Append Files

Stack many Excel files, one below another, into one sheet. Good for 12 monthly files with the same columns.

Steps

  1. Click the upload box and select all your .xlsx files. All files must have the same columns in the same order.
  2. If each file has title lines above the headings, type how many in Skip top rows. If there is a total line at the bottom, type how many in Skip bottom rows. Leave 0 if none.
  3. Click Combine Files.
  4. Check the table shown. The first column, Source File, tells you which file each row came from.
  5. Click Download Excel.

Example

You have Apr.xlsx, May.xlsx, Jun.xlsx. Each has 2 title lines at the top and 1 "Grand Total" line at the bottom.

  • Upload the 3 files. Skip top rows = 2. Skip bottom rows = 1.
  • Click Combine Files. You see all rows of the three months in one table, with Source File = Apr, May or Jun.
  • Download Excel.
TipSkipping applies to every file, so make the files alike before you upload. Only the first sheet of each file is read.
If a file is listed in redThat file could not be read (wrong format or damaged). The other files are still combined.

Need to join files side by side by a matching column (like VLOOKUP)? Use Merge Files instead.
