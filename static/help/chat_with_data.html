Chat with data

Upload your Excel or CSV files and ask questions in plain English. The AI finds the answer, shows a table or chart, and you can pin good answers to a Dashboard.

At the top there is a switch with 4 views: Setup, Chat, Checks, Dashboard. You start in Setup.

1. Setup

Step 1: Upload your files

  1. Click Upload CSV or Excel files and choose your files. You can choose many. Each Excel sheet becomes a table.
  2. Click Load to read them. Open a table's Preview to check it. To remove a table, use its Remove button.

Step 2: How the tables link up

Skip this if you have only one table. With more tables, tell the app which column connects them. Example: the Salary table has Employee Code, and Employee Master also has Employee Code.

  • Click Add a link. Choose the Child table and column (Salary / Employee Code) and the Parent table and column (Employee Master / Employee Code), then Add this link.
  • The app also suggests links. Click Accept on the right ones, or Remove the wrong ones. It warns you if some rows have no match, and lets you see those rows.
  • Click Confirm links when done.

Step 3: What the columns mean

Write a short meaning for each column, for example Basic = monthly basic pay in rupees. This helps the AI answer correctly. Click Suggest with AI to get a first draft, correct it, then Save descriptions.

TipSteps 2 and 3 are optional but make the answers much better, especially with many tables.

2. Chat

Switch to Chat and type your question in the box at the bottom.

You typeWhat you get
Which 5 departments have the highest salary cost?A table with the answer.
Show month-wise sales as a chartA table. Then click Generate chart and, if you like, Customize chart (colours, titles, type).
Add a column Bonus = Basic * 0.12The column is added to your table in this session.
  • Open SQL that ran under an answer to see exactly how the answer was worked out.
  • Actions → Show current data shows your tables as they are now, including added columns.
  • Clear chat empties the conversation. Your tables and links stay.
  • Adding, changing and deleting columns is done by asking in chat. Your original file is never changed.
Ask betterUse the column names as they appear. Say what you want to see. Example: "From Salary, total Net Pay by Department for April, highest first."

3. Pin to Dashboard

Under every answer there is Pin to Dashboard. Click it for each answer you want in your report. It shows "Pinned" once done. Then open the Dashboard page in the left menu to arrange and download them. See that page's help.

4. Checks: find exceptions

Use Checks to test a business rule on your data and list the rows that break it.

  1. Click Add criteria and give it a name, for example Overtime above 50 hours.
  2. Write the rule in plain language: Employees whose overtime hours are more than 50 in a month.
  3. Click Generate & test SQL. The AI writes the query and runs it. You see the exceptions found.
  4. Wrong result? Reword the rule and click Regenerate SQL.
  5. Click Save to report to send the result to the Dashboard page.
  • Save all your rules as a criteria set (Save set) and reload it next month with Load set. It brings back the rules, not the results. Use Run saved SQL to run them on new data.
  • Write summary makes an overview of all the checks.
  • The Actions part can draft an email or note about the exceptions. Check the draft, click Confirm, then Download.

5. Dashboard view

This view builds an interactive web page from your data that works offline.

  1. Click Generate Dashboard. The AI shows a checklist of charts it plans. Edit the list if you like.
  2. Click Build this dashboard.
  3. To change something, click Update the dashboard and say it in a sentence, for example make the first chart horizontal and add a filter for Department. Each visual also has its own Edit button. Undo this brings the earlier version back.
  4. Under Dashboard look and title choose colours and theme.
  5. Click Download this dashboard. You get one HTML file you can email.

6. Chat type: save your setup

If you do the same work every month, save your setup so you only upload new files.

  • At the top type a Name (example: Salary processing) and click Save chat type. It stores the table names, links and column meanings.
  • Next month pick it from Chat type and upload the files. Done.
  • Show schema shows what the chat type expects.

7. Common problems

ProblemWhat to do
The upload box looks empty after I come backYour tables are still loaded. To remove one, use that table's Remove button.
Wrong answerFill Step 3 (column meanings) and Step 2 (links). Then ask again using column names. Open "SQL that ran" to see what happened.
Numbers read as textClean the file first in Utilities → Data cleaner, then use its Export to send it here.
Dashboard page is emptyYou have not pinned anything. Pin answers in Chat first. The dashboard lives only for this session, so download it before closing the tab.
