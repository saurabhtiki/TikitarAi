Report builder

Build a report once, save it as a task, and run it every month with new files. For admins and superusers.

Report builder is like Chat with data, with one big difference: everything you do is written down as a recipe, so next month anyone can run it on new files from the Reports page.

First: pick or create a task

  • To change an old task, pick it and click Open.
  • To make a new one, type a Task name (example: Salary Review) and click Create task.
  • Once open, the name is the heading. Use Rename, Switch task and Save task at the top. A name that already exists updates that task.

The 5 views

A switch at the top has these views, in the order of work: Setup → Report-Items → Checks → Report → Dashboard.

1. Setup

  • Upload a sample of your files (this month's files).
  • How the tables link up: add or accept the links between tables, then confirm them.
  • What the columns mean: write a short meaning for each column. Use Suggest with AI for a draft.
  • At the bottom set the Persona and context (who the report is written as, and what it is about) and an optional Description. The persona is used for all comments in the report.

This is the same as Setup in Chat with data.

2. Report-Items

This is an ordered list. There are two kinds of line:

KindWhat it doesExample
Report itemAsks one question and gives a table, a chart and a comment."Department-wise total net pay."
Column stepChanges the data for every item below it."Add a column Bonus = Basic * 0.12."
  1. Click Add report item (or Add column step) and give it a heading.
  2. Describe it in plain language in What this should show (or The column change).
  3. Click Generate SQL & run. Check the table. Not right? Reword and click Regenerate SQL.
  4. Optionally Generate chart / Customize chart, and Write comment.
  5. Click Pin to report to include it in the report.

The order matters. A column step affects only the items under it.

3. Checks

Write business rules in plain language (example: "Employees with overtime above 50 hours"). The AI writes and tests the query. Save results to the report. Works like Checks in Chat with data.

4. Report

Arrange the pinned items into sections, preview and download. Same as the Dashboard page: Build, then Preview & Download.

5. Dashboard

Build an interactive web page from the data: Generate Dashboard, ask for changes in a sentence, then download. This is saved with the task and can be viewed later from the Reports page.

Finish

  1. Click Save task.
  2. Test it: go to Reports, run the task on a file set and check the output.
  3. Tell your team the task name and the files it expects (the Schema button lists them).
Watch out
  • Each item stores its SQL, so a re-run does not need the AI to produce the numbers (except for rewriting comments, which can be switched off when running). If next month's files change column names, the user will map them during the run.
  • Only the owner can change a task. Other users can run it.
  • If you delete a task, it cannot be brought back.
