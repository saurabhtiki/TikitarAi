User management

Add, change and remove user accounts. Only a superuser can see this page.

Roles

RoleCan do
normal_userUse the tools and run saved reports. Cannot build reports.
adminEverything a normal user can, plus build reports in Report builder.
superuserEverything an admin can, plus manage users.

Add a user

  1. Click Add new.
  2. Type the Email (it must be unique), the Name, and choose the Role.
  3. Type an Initial password and click Save.
  4. Tell the person their email and password. They can change the password in Settings.

Change or remove a user

  1. Click a user's row in the table to select it.
  2. Click Edit to change name, email or role, then Save.
  3. Click Delete to remove the account. You are asked to confirm with Confirm delete.
Protected accountThe first (default) superuser can never be deleted, and its role cannot be changed. This keeps at least one person able to manage the app.
ExampleNew accountant joins. Add her as normal_user so she can run reports. After she learns the tools, change her role to admin so she can build reports.
