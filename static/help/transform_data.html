Transform data

Work with more than one table: join two files, look up a price, add up twelve monthly files, then summarise. You build the work as a list of simple steps.

Data cleaner works on one table at a time. Use Transform data when you need two or more tables together.

The idea

Each step takes a table and creates a new table. The new table can be used in the next step. Like a recipe: step 1, then step 2, then step 3.

Steps

  1. Upload your CSV or Excel files (you can upload many). Each Excel sheet becomes its own table. If asked, choose the sheets and click Load.
  2. Click Add a step. Choose a group and the action, choose which table(s) to use, fill the boxes, click Preview to see the result, then Add step.
  3. Prefer typing? Click Describe a step and write in plain English, for example add a calculated column bonus = salary * 0.12, then click Read it. The app turns it into steps for you to check. It only uses the same actions as the list, so it never writes hidden code.
  4. Repeat. Only the last step can be edited or deleted.
  5. Under Download, choose the tables you want and click Download workbook.
TipEvery cell is first read as text, so codes like 00123 keep their zeros. Before adding or joining on numbers, use Change column type to make that column a number.

Actions available

Example 1: find the price of each sale

You have sales.xlsx (Item, Qty) and prices.xlsx (Item, Rate). You want the amount for every sale.

  1. Upload both files.
  2. Step 1, Look up columns from another table: look up Rate in the prices table. Matching column in sales = Item, in prices = Item.
  3. Step 2, Add a calculated column: new column Amount, formula Qty * Rate.
  4. Step 3, Group and total: group by Item, total up Amount.
  5. Download the workbook.

Example 2: join 12 monthly files

  1. Upload Apr.xlsx ... Mar.xlsx.
  2. Step 1, Append tables: pick all 12 tables. Tick Add a column saying which table each row came from so you know the month.
  3. Step 2, Pivot: rows = Party, columns = month, values = Amount.

Save as pipeline: repeat it next month

  • Save as pipeline stores your uploaded table names and all steps under a name.
  • Next time: pick the pipeline, upload the new files, and run it.
  • Show expected files tells you what files it needs. Update pipeline replaces it with what is on screen.

Send the result onward

Use Export to to send tables to Chat with Data, or to a Report (the app first asks which table is which file the report expects). Start over clears the page.

Watch outIf a step shows a red message, read it. The usual reason is that an earlier step changed or removed a column that this step needs.
