PDF Extracter

Pull numbers and details out of many PDFs (invoices, certificates, statements) into one Excel file. All PDFs must have the same layout.

Steps

  1. Upload PDFs. Select all your PDF files. They must come from the same format (for example all are invoices of the same supplier). Text PDFs work. Scanned photos are not read.
  2. Review extracted fields. The app lists every field it found (json_key) with an example value. Names come from the labels in your PDF. Open Preview extracted data per file to see one file in full. Fields from tables start with T1 |, T2 | ... meaning first table, second table, and so on.
  3. Download Mapping Excel. This gives a starter file with two columns: Output Column Name and JSON Key.
  4. Edit the mapping in Excel. Keep only the fields you want and change the first column to the heading you want. Do not change the second column.
  5. Upload the mapping Excel. The app shows it.
  6. Click Generate Output Excel, check the result, and click Download Output Excel.

Example: GST invoices

You have 20 PDF invoices from one supplier. You want Invoice No, Date and Total.

  1. Upload the 20 PDFs. The app finds fields like Invoice No, Date, Grand Total.
  2. Download the starter mapping. Delete all rows except those three. Change the first column to Bill Number, Bill Date, Amount.
  3. Upload it and click Generate Output Excel. Each PDF gives one line per field: the file name, your column name, and the value. Download.
Watch outIf a field is not found in a PDF, the value is 0. If a result looks wrong, check the key spelling in your mapping. Capital or small letters do not matter.
