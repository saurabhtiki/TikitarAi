Reconcile GSTR-2B

Match your Purchase Register with the GST 3B working file, invoice by invoice, for IGST, CGST and SGST, and update the ITC Availability.

Before you start

  • GST 3B file (.xlsx): must have a sheet named B2B AND B2BA.
  • Purchase Register file (.xlsx): must have a sheet named WORKING.

If a sheet name is different, the app shows an error. Rename the sheet in Excel and upload again.

Steps

  1. Upload the GST 3B file in box 1 and the Purchase Register in box 2.
  2. Rounding-off tolerance (₹). A difference up to this amount is ignored and treated as matched. Default is 1. You can choose 0 to 100.
  3. Click Reconcile.

Reading the result

  • Three tabs: IGST, CGST, SGST. Each shows the total as per Purchase Register, the total as per 3B, and the difference.
  • Reconciled and Unreconciled amounts are shown for both sides, with counts of rows. Open the preview to see the first 50 unreconciled rows.
  • ITC Availability - updated counts shows how many invoices are now marked in each ITC Availability status.
