Reports (ready-made dashboards)

Open a ready-made dashboard in a new tab and see your Excel data as charts and tables.

Steps

  1. In the Report box, pick the dashboard you want (for example Cash Flow Dashboard).
  2. Click Open report. It opens in a new browser tab.
  3. In the new tab, upload your Excel file. The charts and tables fill from it.
Good to know
  • Your Excel file is used only in your own browser tab. It is not sent to the app.
  • The dashboard needs internet to draw its charts.
  • Your Excel must follow the layout the dashboard expects. If it does not fill, check the column headings with whoever gave you the dashboard.
  • If you see "No reports yet", no dashboard has been added. Ask the administrator.
Different from Automate → ReportsThat page runs saved report tasks. This page only opens ready-made HTML dashboards.
